# Intro textures

Downscaled copies of NASA Visible Earth imagery used by the opening zoom. NASA
imagery is in the public domain; credit: NASA Earth Observatory.

| File | Source |
|---|---|
| `earth-day-4096.webp` | Blue Marble Next Generation, December 2004 (`world.200412.3x5400x2700.jpg`), https://visibleearth.nasa.gov/images/74218 |
| `earth-night-4096.webp` | Earth at Night / Black Marble 2016 (`BlackMarble_2016_3km.jpg`), https://visibleearth.nasa.gov/images/144898 |
| `japan-night-128E-152E-26N-46N.webp` | Crop of the Black Marble 2016 3 km image, 128°E–152°E, 26°N–46°N |
| `japan-day-128E-152E-26N-46N.webp` | Crop of the Blue Marble image above, same bounds |
| `earth-clouds-2048.webp` | Blue Marble clouds (`cloud_combined_2048.jpg`), https://visibleearth.nasa.gov/images/57747 |

All images use an equirectangular projection (longitude −180° to 180°,
latitude 90° to −90°).
